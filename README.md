# skyOs
skyOs is my very own web os with a pixel art design.
The project was written with React for easy expansion with apps in the future.

## Features
- Draggable and closable windows
- About App
- Settings App: currently only lets you change your wallpaper, a change which it stores in local storage
- Notes App: A simple notes app that stores it's data in local storage 
- Calculator: It's a calculator...
